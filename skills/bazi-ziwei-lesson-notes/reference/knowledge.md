## A. 八字（子平）

### 1. 四柱結構
- 年柱、月柱、日柱、時柱；每柱一**天干**一**地支**。
- **日干（日主）** = 命主本人；其餘七字論生剋。
- 月柱（月令）氣最強 → 取格、調候之本。

### 2. 十神（以日主為中心）
- 生我：正印、偏印（印星＝母、學識、靠山）。
- 我生：食神、傷官（食傷＝才華、創作、表現）。
- 我剋：正財、偏財（財＝錢、妻、實務）。
- 剋我：正官、七殺（官殺＝事業、名位、約束/權威）。
- 同我：比肩、劫財（比劫＝自我、競爭、同儕）。

### 3. 旺衰 / 調候 / 用神
- **身強身弱**：日主得令、得地、得勢 → 強；反之弱。
- **調候**：按出生月寒暖燥濕補偏救弊（如春木旺需水潤、需金疏）。
- **用神**：全局最需要嗰個五行（扶抑／調候／通關）；用神得力＝順，受合受傷＝災。
- 例（本派常見）：春木身強 → 用金（疏木、生水調候）；金一旦被合走 → 出事。

### 4. 格局
- 建祿、月刃、食神、傷官、財格、官殺格、印格、從格、化格…
- **食傷生財（＋坐官殺）** → 創作型 + 名利型（如名設計師命）。
- **食神制殺 vs 食神見殺**：制得住成貴，制唔住則奔波多爭。

### 5. 神煞 / 大運流年
- 神煞（驛馬、桃花、華蓋、陽刃、孤辰寡宿、空亡…）為輔助象意。
- 大運十年一轉、流年一年一轉；**逢沖合刑害用神之年＝關鍵事件年**。

## B. 紫微斗數

### 1. 十二宮
命宮、兄弟、夫妻、子女、財帛、疾厄、遷移、交友(奴僕)、官祿、田宅、福德、父母。
- 看事業 → 官祿宮；看出國/外緣 → 遷移宮；看根基/財產 → 田宅宮；看心性/福分 → 福德宮。

### 2. 十四主星
紫微、天機、太陽、武曲、天同、廉貞、天府、太陰、貪狼、巨門、天相、天梁、七殺、破軍。
- 廉貞＝才藝/囚/次桃花；七殺＝衝鋒突破；武曲＝財/剛毅（屬金）；天機＝智巧/技術/變動（屬木）；
  天同＝福星（需見煞星刺激先成長）；天府＝庫/貴人（屬土）；太陰＝母/財/陰柔。

### 3. 輔星 / 煞星
- 六吉：左輔、右弼、文昌、文曲、天魁、天鉞。
- 六煞：擎羊、陀羅、火星、鈴星、地空、地劫。
- **四煞（羊陀火鈴）聚一宮 → 居逢四煞**（凶）。

### 4. 四化（祿權科忌）
- 化祿＝財順、化權＝權勢、化科＝名聲、化忌＝阻滯破敗。
- 看大限/流年命宮疊化曜定吉凶；**忌入空宮（如父母空宮）尤重**。

### 5. 格局（示例）
- 紫府朝垣、雙祿夾命、火鈴夾祿（吉）；
- 廉貞七殺路上埋屍、鈴昌陀武、武曲化忌、文昌化忌（凶/死格）。

### 6. 三方四正 / 大限流年
- 命宮 + 對宮 + 三合宮 一同論（三方四正）。
- 大限十年、流年一年；忌煞交集之年論災。

## C. 八字↔紫微 合參原則
- 八字定**五行調候用神**（命脈）；紫微定**星曜格局分布**。
- 兩盤互證：八字用神 ↔ 紫微對應星曜（如金↔武曲）所落宮位 + 化曜旺衰是否一致。
- 應期：兩套各自的大運流年沖合用神/化忌之年互相印證。
- 落斷流程：①八字格局用神 → ②紫微星曜分布 → ③互證 → ④大運流年定應期 → ⑤砌成故事。
