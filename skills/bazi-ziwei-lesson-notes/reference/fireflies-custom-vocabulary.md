# Fireflies 自訂詞彙清單（命理 八字／紫微）

> 貼到 **Fireflies → Settings → Custom Vocabulary**（Pro/Business 才有此功能）。
> 同時把**轉錄語言設為「粵語 / 中文」**（唔好用 auto / English）—— 呢個對準確度幫助最大。
>
> 用法：custom vocabulary 係「教」引擎呢啲係正確詞。下面全部係**正確寫法**，唔係聽錯版本。逐個加入即可。
> （Custom vocabulary 喺源頭防止錯聽；glossary.md 係事後補救。兩者並用。）
